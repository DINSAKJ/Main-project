# Hospital Patient Data Analysis

## Project Overview
This project focuses on cleaning, analyzing, and visualizing hospital patient data using Python. The goal is to understand patient demographics, hospital departments, diagnoses, treatment costs, and payment methods.

## Objectives
- Clean and preprocess hospital patient data.
- Handle missing values and remove duplicate records.
- Correct data types and inconsistent values.
- Identify outliers and invalid data.
- Perform Exploratory Data Analysis (EDA).
- Create charts to identify patterns and trends.

## Dataset Description
The dataset contains hospital patient information with the following columns:

- PatientID
- Age
- Gender
- Department
- AdmissionDate
- DischargeDate
- Diagnosis
- TreatmentCost
- PaymentMode
- PatientStatus

**Dataset Source:** Kaggle

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Load the dataset.
2. Explore the dataset structure.
3. Handle missing values.
4. Remove duplicate records.
5. Correct data types and inconsistent values.
6. Identify invalid values and outliers.
7. Perform Exploratory Data Analysis.
8. Create charts and visualizations.
9. Summarize key findings and insights.

## Visualizations
The project explores:
- Patient age distribution
- Gender distribution
- Department-wise patient count
- Common diagnoses
- Treatment cost distribution
- Payment mode distribution
- Monthly patient admissions
- Age versus treatment cost

## Key Outcomes
- Improved data quality through cleaning and preprocessing.
- Explored patient demographics and department-wise records.
- Analyzed treatment costs and payment methods.
- Visualized patterns and trends in hospital patient data.

## Conclusion
This project demonstrates how Python can be used for data cleaning, Exploratory Data Analysis, and visualization. It helped develop practical skills in data analysis and extracting useful insights from structured datasets.
